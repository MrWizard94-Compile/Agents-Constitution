# Unaccepted proposal queue

These nine patches preserve public proposals while retiring their branch
references. **None is binding law. Do not auto-load or auto-apply them.**
`manifest.json` records each original branch, exact commit and parent, PR,
patch filename and SHA-256. Each patch is the exact binary-capable Git diff
from that commit's parent to the commit, including its original candidate
metadata. Historical versions in patches do not change the active version.
Git attributes preserve patch bytes without newline conversion or text merge;
their context-line spaces and final newlines are part of the patch format.
Open the raw patch to review it; the archive is not executable source.
