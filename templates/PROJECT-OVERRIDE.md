# Project exception request (copy into the project, never fill in source)

This template records a *proposed* exception. It does not grant approval.
Safety, law, platform policy, and the Human Director's exact authorization
remain controlling. A project exception cannot silently remove a protected
rule or relabel a failed gate as N/A.

| Field | Required entry |
|---|---|
| Project and repository | Exact name and canonical Git remote |
| Rule ID and source SHA | Exact rule and frozen Constitution revision |
| Narrow scope and duration | Files, environments, release, expiry |
| Reason and alternatives | Why compliant routes cannot satisfy the need |
| Risk and compensating controls | Security, quality, users, rollback |
| Verification | Reproducible test and evidence path |
| Director decision | Named approval, date, explicit scope or rejection |
| Recheck trigger | Expiry, dependency change, incident, next release |

Keep this record with project law. Update it if the approved scope changes.
